# FullBuff Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build FullBuff — a WoW Forever addon that shows current vs maximum stats with every obtainable buff, lists missing buffs by category with spec-weighted recommendations, and pins their sources on the map — plus the one-command Python pipeline that generates its buff database.

**Architecture:** Part A is a Python build pipeline (`tools/`) that pulls DB2 tables for build 1.60.1.70338 from wago.tools, source data from the installed QuestieDB_Forever and from wowclassicforever.info, applies `tools/curated.yaml`, and emits `addon/FullBuff/Data/*.lua`. Part B is the addon: pure-logic Engine modules (PlayerState, Catalog, Scoring, MaxCalc) consumed by UI modules (Launcher, Popover, DetailCard, Options) and Systems/MapPins. Engine never touches frames.

**Tech Stack:** Python 3.12, pytest, pyyaml, cbor2, lupa (Lua 5.1 runtime for addon tests); WoW Lua 5.1 addon API (Interface 16001); HereBeDragons-2.0 + HereBeDragons-Pins-2.0.

**Spec:** `docs/superpowers/specs/2026-10-13-fullbuff-design.md`

## Global Constraints

- Target: WoW Forever, `## Interface: 16001`, TOC file `FullBuff_Forever.toc`; detect with `WOW_PROJECT_ID == (WOW_PROJECT_CAMELOT or 18)`.
- DB2 build `1.60.1.70338`; Classic Era SpellName build `1.15.9.70003` (only to flag "new in Forever").
- DB2 URL: `https://wago.tools/db2/<Table>/csv?build=<build>`; cache in `tools/.cache/<build>/` (git-ignored).
- QuestieDB path default: `C:\Program Files (x86)\World of Warcraft\_classic_beta_\Interface\AddOns\QuestieDB\QuestieDB_Forever.toc`, overridable with `--questie`.
- One build command: `python tools/build.py --build 1.60.1.70338`.
- Stat keys (exact, used everywhere): `STR AGI STA INT SPI AP RAP SPELL_DMG HEAL ARMOR HP MANA MP5 HP5 CRIT SPELL_CRIT HIT SPELL_HIT` plus `STAT_PCT` (all primary stats %) and `ARMOR_PCT`.
- Category IDs (popover order): `CLASS WORLD CAMPING FLASK ELIXIR FOOD SCROLL WEAPON QUEST TRINKET POTION`.
- Burst = buff duration > 0 and < 600 s. Burst buffs are listed but never counted in the maximum.
- Excluded from the maximum and catalog: passive group auras (duration 0), totems (name contains "Totem"), bag/inventory, use buttons.
- Info only: no secure buttons, no protected calls, no addon messages, no network, no OnUpdate polling.
- Aura reads only when `not InCombatLockdown()` and no returned value is secret (`issecretvalue`).
- Map pins: own pins via HereBeDragons-Pins; never `C_Map.SetUserWaypoint`.
- UI languages: English (default) and Ukrainian (`enUS`, `ukUA`), chosen in options or `/fullbuff lang en|uk`. No Russian.
- SavedVariables: `FullBuffDB` (account), `FullBuffCharDB` (per character).
- License: GPL-3.0 (the generated data embeds data derived from QuestieDB, which is GPL).
- Generated files in `addon/FullBuff/Data/` start with `-- GENERATED by tools/build.py. Do not edit.`

## Review Focus

1. **Character at a level where a class buff's top rank is not castable on them** — expected: the highest rank whose `lvl - 10 <= playerLevel` is used; tested in Task 10.
2. **Player in combat or in an instance with secret aura values** — expected: no aura reads, last snapshot kept and marked stale, no Lua error; tested in Task 9.
3. **Active buff that the database does not know** — expected: not subtracted from the baseline, listed by `/fullbuff debug`, maximum still computed; tested in Task 12.
4. **Two buffs from the same stacking group active at once or a camp buff that replaces a class buff** — expected: only the best one per `excl` group counts; camp buff and its class buff share one group; tested in Tasks 6 and 12.
5. **A buff with several source locations, or none** — expected: the card lists every location and "📍 all" pins them; zero sources shows "source unknown" without error; tested in Task 14.

### Task 2: Buff extraction from DB2

**Files:**
- Create: `tools/model.py`, `tools/extract.py`
- Test: `tools/tests/test_extract.py` (in-memory table fixtures as lists of dicts)

**Interfaces:**
- Consumes: `read_table` rows from Task 1 (dict of table name → rows).
- Produces (in `tools/model.py`):
  - `@dataclass Rank: spell: int; lvl: int; fx: dict[str, float]`
  - `@dataclass Source: kind: str; name: str; mapID: int | None = None; x: float | None = None; y: float | None = None; note: str | None = None`
  - `@dataclass Buff: id: int; name: str; cat: str | None; fx: dict[str, float]; dur: int; lvl: int; excl: str; items: list[int]; burst: bool; new: bool; cls: str | None = None; ranks: list[Rank] | None = None; enchant: int | None = None; sources: list[Source] = field(default_factory=list)`
- Produces (in `tools/extract.py`): `extract_buffs(t: dict[str, list[dict]], era_spell_ids: set[int]) -> tuple[dict[int, Buff], list[Buff]]` returning `(buffs, unclassified)`.

Rules (exact):
- Stat effect = SpellEffect row with `Effect` in {6, 35, 65} and `EffectAura` in the map: 29→primary by `EffectMiscValue_0` (0 STR, 1 AGI, 2 STA, 3 INT, 4 SPI, -1 all five), 137→`STAT_PCT`, 99→`AP`, 124→`RAP`, 13→`SPELL_DMG` (only if school mask has any bit of 126; mask 1 → skip), 135→`HEAL`, 22→`ARMOR` (only when mask == 1), 142→`ARMOR_PCT`, 34→`HP`, 35→`MANA`, 85→`MP5`, 84→`HP5`, 52→`CRIT`, 57 and 71→`SPELL_CRIT`, 54→`HIT`, 55→`SPELL_HIT`. Value = `int(float(EffectBasePointsF))` (the probe confirmed this is the displayed value, e.g. Elixir of Cunning AGI 25).
- Effect 54 (temporary weapon enchant): `EffectMiscValue_0` = SpellItemEnchantment ID; enchant effect type 5 → stat via ITEM_MOD (3 AGI, 4 STR, 5 INT, 6 SPI, 7 STA); type 3 → stats of the referenced equip spell; set `enchant`, `cat = "WEAPON"`.
- Item link: ItemXItemEffect → ItemEffect with `TriggerType == 0`; follow `EffectTriggerSpell` up to depth 2 to find the spell that carries the stat aura; the Buff is keyed by that aura spell ID.
- Item category: InventoryType 12 or ClassID 2/4 on-use → `TRINKET`; ClassID 0 subclass 1 `POTION`, 2 `ELIXIR`, 3 `FLASK`, 4 `SCROLL`, 5 `FOOD`, 6 `WEAPON`; ClassID 12 → `QUEST`; everything else → unclassified (returned in the second list, not in buffs).
- Food eating effects: drop food spells whose fx keys ⊆ {HP5, MP5} and `dur <= 60`.
- Class buffs: spells with `SpellClassOptions.SpellClassSet` in 3–11 (3 MAGE, 4 WARRIOR, 5 WARLOCK, 6 PRIEST, 7 DRUID, 8 ROGUE, 9 HUNTER, 10 PALADIN, 11 SHAMAN), duration > 0, name not containing "Totem"; group ranks by `(class, name)` into one Buff with `ranks` sorted by `lvl` (SpellLevels.SpellLevel), `id` = highest rank spell, `cat = "CLASS"`, `cls` set.
- Long buffs with no item and no class (dur ≥ 600) → unclassified (world candidates; curated decides).
- `dur` from SpellMisc (DifficultyID 0) → SpellDuration ms / 1000; `burst = 0 < dur < 600`; `lvl` = ItemSparse.RequiredLevel for items, lowest rank lvl for class buffs; `new = id not in era_spell_ids`; default `excl = f"{cat}:{name}"`.

### Task 3: QuestieDB reader and source attachment

**Files:**
- Create: `tools/sources/questie.py`
- Test: `tools/tests/test_questie.py`, `tools/tests/fixtures/questie_mini.toc` (built in the test from cbor2 + base64)

**Interfaces:**
- Consumes: `Buff`, `Source` (Task 2); UiMapAssignment rows (Task 1).
- Produces:
  - `load_questie(toc_path: Path) -> QuestieData` where `QuestieData` has `items: dict[int, dict]`, `npcs: dict[int, dict]`, `objects: dict[int, dict]`, `quests: dict[int, dict]` with field names from QuestieDB meta (item: `name`, `npcDrops`, `objectDrops`, `questRewards`, `vendors`; npc: `name`, `spawns`, `subName`; object: `name`, `spawns`; quest: `name`).
  - `area_to_uimap(rows: list[dict]) -> dict[int, int]` (AreaID → UiMapID, lowest `OrderIndex` wins).
  - `attach_sources(buffs: dict[int, Buff], q: QuestieData, amap: dict[int, int]) -> None`.

Format (exact): TOC lines `## X-<Entity>-<id>-<field>: <value>` and `## X-<Entity>-<id>-S: <value>`, entities `Item`, `Npc`, `Object`, `Quest`. Value = base64 of CBOR; a value `~N~` means the real value is the concatenation of keys `<key>-1` … `<key>-N`. `-S` decodes to a scalar row (map field index → value, plus `p` presence bitmask); other keys decode to the table field. Ignore `X-*-IDS` (compressed) — iterate keys instead. Field indices: Item name 1, npcDrops 2, objectDrops 3, questRewards 6, vendors 14; Npc name 1, spawns 7, subName 14; Object name 1, spawns 4 (verify in `src/meta/objectMeta.lua`); Quest name 1. Spawns are `{zoneId: [[x, y, ...], ...]}` with x,y in 0–100.

`attach_sources`: for each item of a Buff → `vendor` Sources (one per vendor NPC spawn), `drop` Sources (NPC/object; cap at 5 locations per item, note "+N more"), `quest` Sources (quest name, no coords). Coordinates: `mapID = amap[zoneId]`, `x = x/100`, `y = y/100`; skip a location whose zone has no uiMap.

### Task 12: Engine/MaxCalc

**Files:**
- Create: `addon/FullBuff/Engine/MaxCalc.lua`
- Test: `tests/lua/test_maxcalc.py`

**Interfaces:**
- Consumes: State, Catalog entries with `recommended`, Scoring.
- Produces: `ns.MaxCalc:Compute(state, catalog) -> { rows: { {stat, current, max, diff} }, missing: Entry[], percentOfMax: number, missingCount: number }`.

Algorithm (exact):
1. `activeFlat` = Σ fx of ACTIVE entries except `STAT_PCT`/`ARMOR_PCT`; `activePct` = Π (1 + STAT_PCT/100) over ACTIVE entries.
2. For each primary P: `base[P] = stats[P] / activePct − activeFlat[P]`.
3. Chosen set = the recommended entry of every `excl` group (non-burst, not UNAVAILABLE). `maxFlat`, `maxPct` from it.
4. `max[P] = (base[P] + maxFlat[P]) × maxPct`; `dP = max[P] − stats[P]`.
5. Non-primary stat S: `max[S] = stats[S] − activeFlat[S] + maxFlat[S] + Σ_P derived(S from dP)` using `Scoring:Expand` on the primary deltas.
6. Rows for `Scoring:RelevantStats(state)` (all stats when `ns.DB.showAllStats`), rounded to 1 decimal for CRIT/HIT/SPELL_* and integers otherwise.
7. `missing` = chosen entries with status CAN_ADD; `percentOfMax` = mean over rows of `current / max` (rows with max 0 skipped) × 100.
Unknown auras are not subtracted.
